# Rehab Ikhlaq — personal website

A single-page site (`index.html`), published with GitHub Pages.

Optional files, added next to `index.html`:

- `photo.jpg` — a portrait; it appears in the About section.
- `cv.pdf` — the CV as a PDF (the "Download PDF" button).
- `cv/index.html` — the CV as a web page at `/cv`. The "View CV" buttons open it, and `/resume` redirects there. Its content mirrors `cv.pdf`, so update both together.
- `cv-preview.jpg` — thumbnail of the CV shown in the CV section. Regenerate it whenever the CV changes.

To add another certification, search `index.html` for `CERTIFICATE`.
